# MRT QR Generator → PDF

Генератор печатных листов с QR-кодами для кодов MRT. Работает в браузере, бэкенда нет. Публикуется через GitHub Pages.

## Файлы

| Файл | Назначение |
|------|-----------|
| `index.html` | Форма + живой шаблон листа + генерация PDF |

## Библиотеки (CDN)

- `qrcodejs` — отрисовка QR на canvas (прозрачный фон)
- `html2canvas` — снимок шаблона листа
- `jsPDF` — сборка многостраничного A4 PDF

## Как пользоваться

1. Введите код MRT, количество листов и подпись (КС).
2. Слайдерами задайте пропорции зон: код / QR / название (сумма всегда 100%).
3. Стиль QR: «Старый» — `SQUA<код>MRT<№ листа>`, «Новый» — только код.
4. «Сгенерировать PDF» — файл `MRT_<код>.pdf`, по листу на страницу.
